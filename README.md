# Creator Outreach Automation

Personal Python automation project built with Selenium for creator outreach and social media workflow organization.

## Overview

This project was created as a personal learning project to explore browser automation, workflow organization, and automated messaging using Python and Selenium.

The workflow was designed to support creator outreach processes and repetitive social media management tasks while learning more about automation tools and software development.

## Features

- Automated profile search workflows
- Browser automation with Selenium
- Automated messaging logic
- Basic profile tracking
- Duplicate-contact prevention
- Session handling

## Technologies

- Python
- Selenium
- Chrome WebDriver

## Project Status

This project is currently being improved and tested as part of my learning process in automation and software development.

## Purpose

Built to continue learning about automation workflows, browser interaction, and Python development through hands-on projects related to creator outreach and digital workflows.
